## 📱 **Mobile Controls**

- **⚔ Attack** (red) - Break blocks/Attack

- **☰ Settings** (top-left) - Toggle HUD display

## ⚡ **Performance Tips**

### **Mobile**
1. Close other apps for better performance
2. Reduce render distance for slower devices
3. Disable gyroscope if not using it
4. Use portrait mode for smaller screen devices
5. Enable airplane mode to reduce lag

### **Desktop**
1. Use fullscreen mode (F11)
2. Lower render distance for weak GPU
3. Disable animated textures for better FPS
4. Close browser tabs

## 🆘 **Troubleshooting**

### **Mobile**
- **Controls not responding?** → Refresh page and tap screen
- **Gyro not working?** → Check permissions in settings
- **Lag/FPS drops?** → Lower render distance
- **Touch not detected?** → Try using 2 fingers for menu

### **Desktop**
- **Can't click?** → Make sure window is focused
- **Mouse locked?** → Press ESC to unlock
- **Can't move?** → Check Caps Lock isn't on
